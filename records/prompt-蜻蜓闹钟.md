# 提示词 · 蜻蜓闹钟（一次交付一个自包含 HTML 文件）

> 用途：给本机引擎（`qwen3.8-27b` / PTQ1_0 档 / 池 8192）一次请求，要一个**能直接双击运行**的成品文件。
> 客户端设置：**回答上限 4096**（页面已钳制，这是池的一半）、温度 `0.7`、思考保持关闭（启动器默认）。

## 0. 实测结论（2026-10-03，本机，先说清楚再给提示词）

| 做法 | 读数 | 结果 |
|---|---|---|
| **一次生成**（下面的主提示词，`max_tokens=4096`） | `finish_reason=length`，产物 11,862 B，**没有 `</html>`**；护栏 `guard_fired` 5→7、`undelivered_final` 1→**2** | ❌ **写不完**：这个成品需要约 3,300+ 输出 token，撞上 4096 上限。护栏如实判负、没把它当成功 |
| **分两步生成**（第二节，两个请求） | 第一步 152.7 s / 8,181 字符（`finish_reason=stop`，闭合）；第二步 141.4 s / 5,114 字符（`stop`）；拼装后 **13,360 B** | ✅ **成功**：闭合、零外部资源、内嵌 JS 经 `node --check` **语法通过** |

⇒ **在本机池 8192 / 上限 4096 下，推荐直接用第二节的两步法**；主提示词留给"池调大之后"或"只要精简版"的场景。

## 一、主提示词（复制这一整段）

```text
请写一个单文件 HTML 网页，双击即可在浏览器打开，实现一个「蜻蜓闹钟」。

硬性要求：
1. 只能是一个 HTML 文件，完全自包含：不允许任何外部资源（不要 CDN、不要外链字体/图片/音频/JS/CSS）；
   样式与脚本全部内联；提示音用 WebAudio 现场合成，不要音频文件。
2. 断网可用；闹钟设置存 localStorage，刷新后仍在。
3. 页面顶部用一行小字写明快捷键：空格=贪睡 5 分钟，Esc=关闭闹铃。

功能：
1. 时间显示：数字时钟 + 指针表盘，两种可切换；用系统时间，每秒刷新。
2. 蜻蜓：用内联 SVG 画一只蜻蜓停在表盘边缘，翅膀随秒针每秒扇动一次；
   闹铃响起时蜻蜓绕表盘盘旋一圈。
3. 闹钟：可添加、删除多个闹钟时间（时:分，24 小时制）；到点触发。
   触发时页面高亮闪烁 + 蜂鸣声由弱到强；提供「贪睡 5 分钟」和「关闭」两个按钮。
4. 交互：用时间输入框添加闹钟；空格贪睡、Esc 关闭。
5. 视觉：深色主题，蜻蜓要有轻量感（翅膀半透明、扇动用 CSS 动画）。

输出格式（严格遵守）：
- 只输出这一个文件的完整内容：从 <!DOCTYPE html> 开始，到 </html> 结束；
- 除了这一个代码块，不要写任何解释、不要写"以下是代码"之类的引导语；
- 必须写完整并闭合。若长度紧张，先精简功能（例如简化动画细节），但文件必须闭合、必须能直接双击运行。
```

## 二、如果被截断：分两次生成（本机池只有 8192，产物长时会发生）

**第一步（骨架 + 样式，不含脚本）**

```text
只写这个「蜻蜓闹钟」单文件 HTML 的骨架与样式：从 <!DOCTYPE html> 到 </html> 完整闭合，
包含数字时钟、SVG 表盘与蜻蜓、闹钟列表区、贪睡/关闭按钮的结构与深色主题 CSS；
不要写任何 JavaScript（留一个空的 <script></script> 占位）。只输出这一个代码块。
```

**第二步（补脚本）**

```text
下面是我已有的蜻蜓闹钟 HTML。请只输出要插入到它 </body> 之前的那个 <script> 块（含 <script> 与 </script> 标签），
实现：每秒走时、秒针扇翅、闹钟到点触发（WebAudio 由弱到强的蜂鸣）、贪睡 5 分钟、Esc 关闭、localStorage 保存。
不要重复输出 HTML 结构，不要解释。
（此处粘贴第一步产出的 HTML）
```

## 三、怎么判断"成了"（别把"有文件"当成"文件能用"）

| 判据 | 通过的样子 |
|---|---|
| 文件闭合 | 结尾有 `</html>`；若回答里出现 `[交付检查未通过：TRUNCATED …]`，说明**被截断过**，按第二节分两次做 |
| 自包含 | 全文搜不到 `http://` / `https://` / `.mp3` / `.png` / `cdn`（除了 `<!DOCTYPE html>` 之类） |
| 真能跑 | 存成 `.html` 双击 → 时钟在走、蜻蜓翅膀在扇、加一个 1 分钟后的闹钟能响、空格能贪睡 |
| 护栏读数 | `http://127.0.0.1:8097/stats` 里 `undelivered_final` 不应增长；若增长 = 该轮产物不合格（手册 §3） |

> 说明：本机聊天页会在同一条响应流里自动判定 `TRUNCATED`（`finish_reason=length`、围栏未闭合、`<svg>` 无 `</svg>`）
> 并**带着纠正指令重发最多 2 次**。看到 `[交付检查未通过：… 第 N 次重试]` 是护栏在工作，不是引擎坏了。
